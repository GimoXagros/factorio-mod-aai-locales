# AAI Locales [Addon]

## Repository version and installation

This repository contains `aai-locales` source version `1.2.0`. Its [info.json](info.json) declares Factorio `0.17`. These metadata describe this checkout and do not establish compatibility with newer Factorio versions.

For packaged installation, use the [aai-locales Mod Portal downloads](https://mods.factorio.com/mod/aai-locales/downloads) and select a file for your installed Factorio version. Portal releases can differ from this checkout. Put the downloaded mod ZIP in your Factorio user data `mods` directory and install the required dependencies listed in the manifest; entries prefixed with `?` are optional.

GitHub Releases in this repository: [1.1.0](https://github.com/GimoXagros/factorio-mod-aai-locales/releases/tag/1.1.0) (prerelease). Check their version separately from the source manifest.
